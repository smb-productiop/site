# Site SMB

1. Mets ton logo dans `assets/logo.svg` (sans ça, le texte "SMB" s'affiche).
2. Ouvre `index.html` dans ton navigateur pour voir le site.
3. Pour ajouter un projet : ouvre `projects.js`, copie un bloc, change les infos.

## Mise en ligne (GitHub Pages)
1. Crée un compte sur github.com, puis un dépôt public (ex. `smb-site`).
2. "Add file" > "Upload files" : glisse tout le contenu de ce dossier, puis "Commit".
3. Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`.
4. Après 1 à 2 minutes, le site est en ligne sur `https://TONPSEUDO.github.io/smb-site/`.
5. Domaine perso (optionnel) : Settings > Pages > Custom domain.
